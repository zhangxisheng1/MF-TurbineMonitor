# 风机疲劳监测与智能调控数字孪生驾驶舱（前端演示）

## 1) 项目名称
风机疲劳数字孪生驾驶舱 Demo

## 2) 项目定位
这是一个**前端数字孪生演示系统**，用于答辩/汇报展示，不连接真实工业后端与控制器。

## 3) 技术栈
- React + TypeScript + Vite
- Tailwind CSS
- ECharts

## 4) 页面结构
- 顶部状态栏：标题、时间、天气、风场状态、选中机组
- 左侧面板：运行总览、机组列表、事件流、趋势图
- 中央主视觉：主风机数字孪生焦点 + 风场科技背景
- 右侧面板：疲劳指标、健康状态、温度分布、调控状态、多图表
- 底部控制区：视图切换、暂停/继续、刷新速度、窗口切换

## 5) mock 数据仿真说明
- 在 `src/mock` 中实现本地仿真器，支持 12 台风机。
- 按趋势项+周期项+平滑惯性生成运行参数，并进行指标联动。
- `cumulativeDamage` 由 `damageRate` 积分，单调递增。
- 告警由阈值逻辑触发（非随机）。

## 6) 演示规则 vs 真实接口替换
演示规则：
- 风速、转速、功率、扭矩、推力、疲劳、温度、告警、调控建议全部由前端规则生成。

可替换真实接口：
- `src/mock/simulator.ts` 的 `step()` 可替换为实时 API 推送。
- `src/mock/generators.ts` 可替换为后端计算结果。
- UI 组件无需重写，只改数据来源。

## 7) 如何启动
```bash
npm install
npm run dev
```

## 8) 默认访问地址
`http://localhost:5173`

## 9) 适合展示场景
- 数字孪生方案演示
- 风机疲劳监测架构答辩
- 智能调控逻辑可视化汇报

> 说明：当前版本为前端演示规则，不代表真实工业控制策略。
